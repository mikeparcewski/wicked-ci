# garden: the skill catalog, hooks, launcher, packs and site

## Setup quirks

- **The plugin install is a prerequisite.** About a third of garden capabilities depend on
  `garden.plugin.cc.marketplace-install`. A scenario's own setup performs it in a sandbox; it is
  recorded as a prerequisite, never done against the operator's real CLI config.
- **Python and node.** Garden scripts need `python3` (some `python>=3.10`) and the launcher needs
  `node>=20`. Both are probed on PATH.
- **Garden's own tests have no adapter yet.** Capabilities proven only by wicked-garden's test
  suite report `skipped: adapter:none`.
- **Evidence chain.** Garden's prove and QE capabilities depend on `wicked-vault` and
  `wicked-ledger` (see `refs/foundation.md`).
- **Browsers.** The site and render capabilities need Chromium (`chromium` deps).
